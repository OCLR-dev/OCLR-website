# S5 全量統計核對（現有資料）

核對範圍：34 場、332 局、70 個比賽圖池 slots。這是離線來源核對，沒有修改正式站、原始名單、比分或發布統計。

## 核對結果

- 32 場原始加總比分與已核准比分一致；B28 與 GF 不一致。比分一致只證明算術核對，不代表身份、候補紀錄或技術裁定已獲批准。
- 251 局完整圖池內對局為計分候選；18 局未完成且全部分數為 0；63 局完整對局不在該階段圖池。後兩者不進候選統計，未把所有圖池外對局一概稱作暖身。
- 34 場候選局數均等於已核准比分總局數；12 隊的系列賽勝敗與勝負圖數均與已保存的最終名次表一致。沒有更動名次。
- 原始分數、零分紀錄、玩家 UID 與 Mods 全部保留；不因低分、教練或裁判身份自動排除。缺少的 ACC／Combo／命中數維持未知。

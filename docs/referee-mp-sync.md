# 裁判面板 MP 比分同步

裁判在執裁工作臺展開「MP 比分同步」，貼上官方 MP 連結並綁定。可在 BP 開始前綁定；綁定不會自行建立選圖或決定先 Ban／先 Pick。來源預覽與暫記比分均屬工作人員私人資料，正式賽果仍經 MP 審核、提交及 Admin 核准／發佈。

面板開啟時自動檢查：前景約 30 秒、背景約 60 秒。重載會恢復保存的綁定及比分，重新讀取來源；關閉頁面後沒有獨立排程持續抓取，已送出的同步請求仍可能完成。停止同步保留已有紀錄；重新綁定不重播舊局或自動修改人工裁決。

## 哪些結果會自動入分

沿用現有官方 osu! API client、完整歷史解析與 `previewMatch` 計分器。只有以下證據全部成立，才記錄當前選圖的勝方：

- 精確對應目前有效的 Pick／TB 圖譜及第一個 attempt，且 MP 內僅有一次該圖譜；不靠房名、隊名文字或房內紅藍色猜測隊伍。
- 選圖紀錄先於遊戲開始；開始／結束時間有效，局已結束，來源歷史完整且沒有異常警告。房間仍開啟屬於正常的即時同步狀態，不要求關房才計分；目前仍進行中的 game 不入分。
- 玩家 UID 依本場保存的有效隊員名單歸屬，隊伍、人數、規則、計分方式及 EX 人數均可確定。
- 已保存的固定 Mods 與房間／玩家有效 Mods 相符；資料沒有失敗、未知、平手、陣容或規則異常。
- 該 MP game 未在其他自動記分或另一場的正式賽果中占用；沒有人工結果或待處理的自動結果修正。

Free Mod／Force Mod 的個人限制仍需人工核對，因此列為待核對，不因取得分數就宣稱規則合規。重複圖譜（含暖身與重賽）、明示重賽 attempt、未對應選圖、時間不符、平手、不完整或其他異常也不自動選勝方。

## 人工核對與來源變動

「待人工核對」列出 MP game／BID 與原因，並提供「核對執裁紀錄」入口。沿用原有勝方、中止及重賽控制；較早選圖的修正仍須先撤回後續步驟。不同 game 不會被自動當作同一次重賽。

自動結果保存不可變來源快照、逐局雜湊與 ledger event ID。後續完整且可採信的來源修改、刪除已計分的局、出現重複圖譜，或場次依賴改變時，只撤回仍由自動同步持有的暫記分：追加中止／待核對結果，保留歷史及稽核，不決定新的勝方。裁判明確改判後，其人工 event 取得結果控制權，後續輪詢不覆寫。待核對的自動結果未處理前暫停新增自動分數。

新局／來源事件增加不會單憑整份 snapshot fingerprint 改變就撤回先前正常局；逐局證據獨立比對。即時分頁暫時不完整時也保留已核對的舊局，只暫停新增，待完整讀取後才判斷來源變更。provider 暫時失敗保留上次保存的結果及成功檢查時間，顯示錯誤並延後重試，不把未知當作零分。

## 接口與一致性

`POST /api/admin/tournaments/{edition}/matches/{fixture}/referee/mp` 接受有限 action：

- `status`：只讀取保存的綁定及工作臺，沒有 provider I/O 或業務寫入。
- `bind`：官方 MP ID／連結、目前綁定 revision、session revision 與 dependency fingerprint。
- `unbind`：目前綁定 revision，停用並隔離尚未回覆的同步。
- `sync`：目前綁定 revision；伺服器自行抓取並計分，不接受 client winner、分數或來源內容。

全部要求同源 cookie、有效登入及本場權限；bind／sync／unbind 重新檢查工作人員、版次及場次狀態。唯讀 Developer／remote channel 無此業務入口。provider 請求只走固定 osu! client，不對輸入網址發任意 HTTP 請求。

短交易按既有裁判鎖順序取得跨程序 lease 與 30 秒冷卻，再於交易外抓取。回覆落庫前重新驗權、版本、lease 及依賴；取消、重新綁定或其他 worker 取得新 lease 後，舊回覆不能寫入。逐局唯一索引、來源去重與 ledger／receipt／稽核同一交易，避免多頁籤、重試或遺失回應重複加分。前端也忽略較舊 revision，防止慢速 IRC 投影覆蓋新比分。

`0067_referee_mp_auto_score` 新增私人綁定及自動結果證據表。部署需依正常更新流程套用遷移；本次開發不執行正式遷移、部署或真人 Bancho 操作。既有 desktop panel DTO 與 ledger event 類型不變。

驗證使用合成 osu! 資料、獨立 PostgreSQL，以及針對桌面／手機輪詢、比分更新與人工核對入口的瀏覽器測試。實際結果以 PR 的提交與 CI 證據為準；合成驗證不代表正式網站已部署或真實 provider 聯調已驗收。
